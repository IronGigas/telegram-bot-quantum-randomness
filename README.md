*Название проекта:*  
Quantum Randomness Bot  
  
*Описание проекта:*  
Этот бот использует API Австралийского национального университета (ANU) (https://qrng.anu.edu.au).  
Они измеряют квантовые флуктуации вакуума для генерации истинно случайных чисел.  
В отличие от обычных компьютерных алгоритмов, эти числа невозможно предсказать.  
Бот принимает список произвольных значений и на основе рандомных байт полученных от ANU выбирает одно из них. Таким образом получается подлинно не детерминированный выбор коренящаяся в фундаментальной квантовой неопределённости вакуума - её нельзя предсказать заранее никаким классическим способом.  
  
*Как использовать:*  
Найти в Телеграме бот @quant_rnd_bot и далее следовать его инструкциям.  
  
*Как скомпилировать и запустить:*  
Для работы бота потребуется телеграмный токен, его можно получить у @BotFther и вставить в файл main.go в переменную botToken  
Компиляция и запуск зависят от операционной системы на которой будетработать бот, примел для Linux:  
GOOS=linux GOARCH=amd64 go build -o bot main.go  
Затем запустить в nohup, либо как отдельный сервис.  
nohup ./bot > bot.log 2>&1 &
